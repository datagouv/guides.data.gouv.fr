# Citer un jeu de données

Les jeux de données publiés sur data.gouv.fr peuvent disposer d’un DOI afin de faciliter leur citation et leur référencement.

{% hint style="info" %}
Un DOI, pour _Digital Object Identifier_, est un identifiant unique et pérenne. Contrairement à une simple adresse web, il identifie durablement une ressource et permet de la retrouver dans le temps.
{% endhint %}

L’attribution d’un DOI facilite la citation des données dans les travaux de recherche, les publications, les études et les autres réutilisations. Elle contribue aussi à reconnaître les jeux de données comme des ressources citées et référencées, ainsi que le travail de leurs producteurs.

### Citer un jeu de données

Utilisez le DOI lorsqu’il est disponible. Complétez la citation avec les informations suivantes :

* le producteur ou l’organisation qui publie le jeu de données ;
* le titre du jeu de données ;
* sa date de publication ou de mise à jour, lorsqu’elle est disponible ;
* le DOI du jeu de données.

Le DOI pointe vers une adresse pérenne. Il reste le meilleur identifiant à utiliser pour référencer le jeu de données.

### Trouver ou demander un DOI

<figure><img src="../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>

Le DOI apparaît dans l’onglet **Informations** de la page du jeu de données.

S’il n’est pas affiché, vous pouvez demander la création d’un DOI pour ce jeu de données.

Pour les jeux de données moissonnés depuis une autre plateforme, le DOI est récupéré avec les métadonnées lorsqu’il est disponible sur la plateforme source.
