# Gérer vos notifications

Les notifications vous informent des événements liés aux contenus et discussions que vous suivez.

{% hint style="info" %}
Les favoris et les notifications sont distincts. Mettre un jeu de données, une réutilisation ou une API en favori ne vous abonne pas à ses notifications.
{% endhint %}

### Notifications reçues

Vous pouvez être notifié lorsqu’une discussion est ouverte, reçoit une réponse ou est clôturée. Vous pouvez aussi recevoir des alertes pour une nouvelle réutilisation ou API associée à un jeu de données.

Les notifications couvrent également les invitations d’organisation, les demandes de transfert, les badges d’organisation et la validation d’un moissonneur.

### Selon votre rôle

{% tabs %}
{% tab title="Administrateur d’organisation" %}
Les administrateurs suivent par défaut les contenus de leur organisation. Vous pouvez désactiver les alertes d’un contenu, d’une discussion ou d’une catégorie.
{% endtab %}

{% tab title="Éditeur et éditeur partiel" %}
Lorsqu’un éditeur crée ou modifie manuellement un contenu, il le suit automatiquement. Participer à une discussion active aussi ce suivi.

Un éditeur partiel reçoit les notifications liées aux contenus qui lui sont attribués.

Les opérations réalisées par script, clé API, application OAuth ou moissonneur n’activent pas ce suivi automatique.
{% endtab %}

{% tab title="Sans rôle dans l’organisation" %}
Vous recevez les réponses aux discussions auxquelles vous participez. Vous pouvez aussi suivre une discussion, les nouvelles discussions d’un contenu, ou certains contenus proposés.
{% endtab %}
{% endtabs %}

### Modifier vos préférences

1. Connectez-vous à data.gouv.fr.
2. Ouvrez votre espace d’administration.
3. Sélectionnez **Notifications** dans le menu du profil.

Vous pouvez notamment arrêter le suivi d’une discussion, d’un contenu, d’une catégorie ou d’une organisation. Vous pouvez aussi mettre toutes vos notifications en pause.

{% hint style="warning" %}
Les notifications nécessitant une action restent actives. Elles concernent par exemple les invitations, les transferts et la validation d’un moissonneur.
{% endhint %}

### Rythme des e-mails

Choisissez l’un des rythmes suivants :

* **À chaque fois** : envoi immédiat ;
* **Un résumé par jour** ;
* **Un résumé par semaine**.

Mettre les notifications en pause suspend aussi les e-mails, sauf ceux qui nécessitent une action.
