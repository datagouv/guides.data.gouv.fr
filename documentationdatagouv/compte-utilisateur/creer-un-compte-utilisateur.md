# Créer un compte utilisateur

## Pourquoi créer un compte utilisateur ?

{% hint style="info" %}
Il n’est pas nécessaire de créer un compte pour télécharger des jeux de données sur [data.gouv.fr](https://www.data.gouv.fr).
{% endhint %}

Un compte utilisateur vous permet de :

* Publier des jeux de données ;
* Publier une API ;
* Référencer des réutilisations ;
* Publier des commentaires ;
* Suivre les publications d’autres utilisateurs ;
* Créer ou rejoindre une organisation.

***

## Comment créer un compte utilisateur ?

{% hint style="info" %}
🔐 Pour des raisons de sécurité, il est recommandé d’utiliser un **compte nominatif** (évitez les comptes partagés).
{% endhint %}

1. Dans le menu, cliquez sur <img src="../.gitbook/assets/image (38) (1).png" alt="" data-size="line">en haut à droite
2. Renseignez votre **prénom**, **nom** et **adresse e-mail** ;
3. Choisissez un **mot de passe** et confirmez-le ;
4. Acceptez les **conditions générales d’utilisation** ;
5. Cliquez sur **« S’enregistrer »**.

Une fois ce formulaire rempli :

* Un message à l’écran vous invite à confirmer votre adresse e-mail ;
* Rendez-vous dans votre boîte de réception (vérifiez vos spams si besoin) ;
* Ouvrez l’e-mail envoyé par `no-reply@data.gouv.fr` et cliquez sur **« Confirmer maintenant »**.

Vous serez alors redirigé vers la page d’accueil, connecté à votre compte utilisateur.

Vous pouvez aussi créer votre compte avec [ProConnect](https://www.proconnect.gouv.fr/) <img src="../.gitbook/assets/image (39) (1).png" alt="" data-size="line">, l’accès des professionnels validé par l’État (public comme privé). La connexion demande alors en général une double authentification, décrite ci-dessous.

Vous pouvez maintenant commencer à publier, commenter ou rejoindre une organisation ! :white\_check\_mark:

## La double authentification

La double authentification ajoute un code à 6 chiffres à votre mot de passe. Ce code s’affiche dans une application sur votre téléphone et change tout seul toutes les 30 secondes.

### Quelle application installer ?

Installez [FreeOTP](https://freeotp.github.io/) ou [Proton Authenticator](https://proton.me/fr/authenticator) : les deux sont gratuites.

### Avec ProConnect

Si vous vous connectez avec ProConnect, ce code vous sera probablement demandé.

La première fois, ProConnect affiche un QR code. Scannez-le avec [l’application que vous avez choisie](creer-un-compte-utilisateur.md#quelle-application-installer), puis saisissez le code à 6 chiffres.

### Avec un compte data.gouv.fr

Vous pouvez aussi activer cette protection sur votre compte data.gouv.fr, depuis votre [profil](https://www.data.gouv.fr/admin/me/profile). C’est facultatif pour le moment. Le principe est le même : scannez le QR code proposé, puis saisissez le code à 6 chiffres.

Les fois suivantes, ouvrez la même application et recopiez le code affiché.
